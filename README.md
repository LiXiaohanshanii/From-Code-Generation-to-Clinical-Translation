# From-Code-Generation-to-Clinical-Translation
This repository contains code and methodological evaluation materials associated with the study:
**From Code Generation to Clinical Translation: Evaluating LLM-Assisted Clinical Machine Learning in Laboratory Medicine**

**Repository Structure**
01_generated_code/
├── TRUST/
└── CrAg/

02_llm_outputs/
├── TRUST/
└── CrAg/

03_statistical_analysis/
└── Statistical analysis for the 200-run TRUST.py

04_clinical_models/
├── TRUST_final.py
├── CrAg_multi_threshold.py
├── CrAg_1_80_development.py
└── CrAg_1_80_validation.py

**Generated Code**
01_generated_code/ contains the Python scripts generated by the evaluated LLMs and used for technical executability and methodological adequacy assessment.
TRUST code files follow the naming convention described in the manuscript and correspond to the 5 LLM × 2 reasoning modes × 2 prompts × 10 repetitions benchmark.
CrAg code files correspond to the cross-task and safeguard-prompt experiments.

**LLM Outputs**
02_llm_outputs/ contains archived Word documents of the original user-visible LLM responses.
For reasoning-enabled runs, any thinking or reasoning text visibly displayed in the model interface was retained together with the final response.
The executable Python code extracted from these responses is provided separately in 01_generated_code/.
**TRUST output files follow:**
LLM_OUT_TRUST-[LLM]-[Mode]-[Prompt].docx
**CrAg output files follow:**
LLM_OUT_TRUST-[LLM]-[Mode]-[Prompt]-B,C.docx
Prompt templates are provided in the Supplementary Materials of the manuscript and are not duplicated here.

**Statistical Analysis**
03_statistical_analysis/ contains the statistical analysis code for the 200-run TRUST benchmark, including:
Pass@1
Methodological Adequacy Rate (MAR)
Token consumption
Pylint score
Code lines
Comment density
Corresponding statistical comparisons and multiple-testing procedures

**Clinical_Modeling**
04_clinical_models/ contains the scripts used for:
Final TRUST model development
CrAg multi-threshold development analysis
Final CrAg ≥1:80 model development
Temporal validation of the CrAg ≥1:80 model

**Data Availability**
No patient-level clinical data or synthetic/example datasets are included in this repository.
Clinical datasets are subject to institutional ethics, privacy, and data-governance restrictions.

**Environment**
The analyses were performed using the Python environment and package versions reported in the manuscript.
